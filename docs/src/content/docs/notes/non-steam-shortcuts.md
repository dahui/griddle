title: Non-Steam shortcuts
description: Artwork for games you added to Steam yourself, and why their icons need Steam closed.

Games you added with **Add a Non-Steam Game** work like any other in Griddle, with two
differences.

## Griddle cannot look them up automatically

A non-Steam shortcut's ID is generated by your own Steam install, so SteamGridDB has never seen
it. Griddle searches by name instead, which is usually right and occasionally not — use **Wrong
game?** to pick the correct entry, and it will be remembered.

## Icons show at the next Steam start

Capsules, heroes and logos apply instantly, exactly as they do for Steam games. **Icons never
do** — for shortcuts or for Steam games. Apply one and Griddle says so; it is there the next time
Steam starts.

**Griddle does not close or restart Steam.** A shortcut's icon is stored in `shortcuts.vdf` rather
than as artwork, and Steam keeps that file in memory while it runs — so Griddle asks Steam itself
to make the change and lets Steam save the file, which is what the Decky plugin does too. With
Steam closed it edits the file directly instead. Either way you do not have to do anything.

The original `shortcuts.vdf` is copied to `shortcuts.vdf.sgdb-orig` before the first change, once,
and never overwritten afterwards.

## Steam games take icons too

They just need a restart, like every icon does. Apply one from the Icon tab and Griddle writes it
and says so; it appears the next time Steam starts. No shutdown is needed, because a Steam game's
icon is not kept in `shortcuts.vdf` — only shortcuts are.
