Games you added with **Add a Non-Steam Game** work like any other in Griddle, with two
differences.

## Griddle cannot look them up automatically

A non-Steam shortcut's ID is generated by your own Steam install, so SteamGridDB has never seen
it. Griddle searches by name instead, which is usually right and occasionally not — use **Wrong
game?** to pick the correct entry, and it will be remembered.

## Icons need Steam closed

Capsules, heroes and logos apply instantly, exactly as they do for Steam games. **Icons do not**,
because a shortcut's icon is stored in `shortcuts.vdf` rather than as artwork, and Steam keeps
that file in memory while it runs. Anything written to it while Steam is open is discarded when
Steam exits.

So when you set an icon, Griddle:

1. Asks Steam to shut down and waits for it to actually finish — including the helper processes,
   which outlive the main one.
2. Writes the icon and updates `shortcuts.vdf`.
3. Reads the file back and checks it matches what was intended.
4. Starts Steam again.

If Steam will not close — a game still running, or a dialog waiting for an answer — Griddle stops
and says so rather than writing a file that would be thrown away.

The original `shortcuts.vdf` is copied to `shortcuts.vdf.sgdb-orig` before the first change, once,
and never overwritten afterwards.

## Steam games cannot have a custom icon at all

This is a Steam limitation, not a missing feature. The call that sets every other artwork type
accepts an icon and then does nothing — no file is written and no error is raised. Griddle shows
the current icon for Steam games and disables the control, rather than offering a button that
silently fails.
