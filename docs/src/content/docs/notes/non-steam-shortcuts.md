Games you added with **Add a Non-Steam Game** work like any other in Griddle, with two
differences.

## Griddle cannot look them up automatically

A non-Steam shortcut's ID is generated by your own Steam install, so SteamGridDB has never seen it.
Griddle searches by name instead, which is usually right and occasionally not.

Expand **Filters** above the results to see which game it matched, and click that button to pick a
different one. See
[when Griddle matches the wrong game](/griddle/using/finding-your-games/#when-griddle-matches-the-wrong-game).

## Icons show at the next Steam start

Capsules, heroes and logos apply instantly, exactly as they do for Steam games. **Icons never do**,
for shortcuts and Steam games alike. Apply one, Griddle tells you, and it is there the next time
Steam starts.

**Griddle never closes or restarts Steam for this**, and there is nothing for you to do. It keeps a
one-time copy of the original `shortcuts.vdf` as `shortcuts.vdf.sgdb-orig` before its first change.
