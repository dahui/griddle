This walks through changing one game's portrait capsule — the tall image Steam shows in your
library grid.

## 1. Pick a game

Griddle opens on your library. By default it lists **installed** games; the **All games** tab
widens that to everything Steam has a record of on this PC.

Type in the filter box to narrow the list, then click a game to open it.

<Image src={library} alt="The library grid, showing installed games as portrait capsules" />

## 2. Check what it has now

The **Current** tab shows all five slots side by side and what each one holds today. Anything you
have not customised is labelled *Steam default*.

<Image src={current} alt="The Current tab, showing capsule, wide capsule, hero and logo side by side" />

## 3. Browse replacements

The **Capsule** tab searches SteamGridDB for that game and shows what is available. Scroll for
more; results load as you go, and the count above reads *loaded of total*.

<Image src={browse} alt="The Capsule tab with the filter panel open and candidate artwork below" />

If Griddle matched the wrong game — which happens with re-releases and remasters — use
**Wrong game?** at the top to search by name and pick the right one.

## 4. Apply it

Click any result. Griddle applies it and, in most cases, **your Steam library updates
immediately** — no restart. Switch to Steam and look.

If Steam is not running, Griddle writes the artwork to disk instead and tells you it will appear
the next time Steam starts. Either way it says which of the two happened.

**Not sure which of two similar images to pick?** Right-click one for its details — who made it,
its exact size and format, its style, and how it has been voted on — with an **Apply** button
there too. On a controller this is **Y**.

## If you want it back

Right-click the slot and choose **Reset**, or use **Reset all artwork** in Settings.
[What that deletes](/griddle/using/resetting-artwork/) is spelled out before it happens.
