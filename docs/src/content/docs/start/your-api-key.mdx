Griddle opens on a welcome screen the first time it runs, and asks for a **SteamGridDB API key**.
It is free, and it takes about a minute. The same four steps are on that screen, with a button
that opens the right page for you.

<Image src={welcome} alt="Griddle's first-run welcome screen, with the four steps and the key field" />

## Getting one

1. Sign in at [steamgriddb.com](https://www.steamgriddb.com/) (a Steam login works).
2. Open your **profile → Preferences → API**.
3. Generate a key and copy it.
4. Paste it into Griddle when it asks, or later under **Settings → API key**.

Griddle checks the key with SteamGridDB before saving it, so a bad one shows up right away. If what
you pasted doesn't look like a key, it says so but still lets you save: that check is a hint, not a
rule.

Afterwards the key lives under **Settings → SteamGridDB API key**, where you can replace or remove
it.

<Image src={settings} alt="Griddle's settings screen, showing the API key panel" />

## Why yours and not one built in

A key inside a downloaded app gets extracted, over-used and then revoked, taking every installation
down at once. That is not hypothetical: the Decky plugin Griddle replaces has one hardcoded, and it
returns **401** for everyone today.

Your own key is rate-limited to your own use, and nobody else's behaviour can break it.

## How Griddle stores it

Your key is encrypted with **Windows DPAPI**, scoped to your Windows account. So it is never on
disk in plain text, another account on the same PC cannot read it, and it is only ever sent to
SteamGridDB, never with image downloads.

One consequence: a settings file copied to another machine or another Windows account will not
decrypt. Griddle says so on the welcome screen and keeps the rest of your settings, so you just
paste the key back.
